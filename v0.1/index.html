trade-agent-profile v0.1

これは実験的な参照仕様です。いずれの標準化団体の公式仕様でもありません。
判断するのは利用者です。このツールは下調べと記録を担います。

This is an experimental reference specification. It is not an official specification of any standards body.
The user makes the decisions. This tool only helps with preliminary checks and record keeping.

https://trade-agent-profile.github.io/v0.1 は、貿易用プロファイル 0.1.0 を A2A の拡張として識別する URI です。AgentCard の capabilities.extensions に、この URI を書いて宣言します。意味が変わる版では、新しい URI になります。

https://trade-agent-profile.github.io/v0.1 identifies version 0.1.0 of the trade profile as an A2A extension. Declare it in the AgentCard's capabilities.extensions. A version that changes meaning gets a new URI.

{
  "uri": "https://trade-agent-profile.github.io/v0.1",
  "required": true,
  "params": {
    "profile": "trade-agent-profile",
    "profile_versions": [
      "0.1.0"
    ]
  }
}

roles と accepts の書き方は、仕様の第4.1節にあります。 / See section 4.1 of the specification for roles and accepts.
